## 📌 صورت مسئله

در این تمرین، با استفاده از دیتابیس `used_cars.csv` که حاوی اطلاعاتی از **قیمت فروش خودروهای کارکرده** به همراه چندین ویژگی دیگر است، بخش‌های زیر را پیاده‌سازی کنید.

---

## 🗂️ مراحل پیاده‌سازی

### ۱. پیش‌پردازش داده‌ها (Data Preprocessing)

انجام عملیات لازم برای آماده‌سازی داده‌ها، مانند:

- مدیریت مقادیر گمشده (Missing Values)
- تبدیل فرمت‌ها
- و سایر عملیات لازم

### ۲. مصورسازی داده‌ها (Data Visualization)

استفاده از نمودارها و گراف‌ها برای درک بهتر:

- توزیع داده‌ها
- روابط بین ویژگی‌ها

### ۳. تقسیم داده‌ها (Train/Test Split)

تقسیم مجموعه داده به دو بخش:

- **آموزش (Train):** برای آموزش مدل‌ها
- **آزمون (Test):** برای ارزیابی عملکرد مدل‌ها

### ۴. اعمال مدل‌های رگرسیون

بر روی داده‌های آموزشی، مدل‌های رگرسیون زیر را اعمال کنید:

| # | مدل | توضیح |
|:-:|:---|:---|
| ۱ | **رگرسیون خطی تک‌متغیره** (Simple Linear Regression) | مدلی برای پیش‌بینی با استفاده از *یک* متغیر مستقل |
| ۲ | **رگرسیون خطی چندمتغیره** (Multiple Linear Regression) | مدلی برای پیش‌بینی با استفاده از *چندین* متغیر مستقل |
| ۳ | **رگرسیون چندجمله‌ای** (Polynomial Regression) | مدلی برای پیش‌بینی روابط غیرخطی بین متغیرها |
| ۴ | **Ridge Regression** | رگرسیون با جریمه **L2** برای جلوگیری از overfitting |
| ۵ | **Lasso Regression** | رگرسیون با جریمه **L1** برای انتخاب ویژگی‌ها |
| ۶ | **Elastic Net Regression** | ترکیبی از جریمه‌های **L1** و **L2** |

> 🔧 برای هر یک از مدل‌های رگرسیون با روش‌های تنظیم (Ridge، Lasso و Elastic Net)، **بهترین هایپرپارامترها** را پیدا کنید.

### ۵. ارزیابی عملکرد مدل‌ها

عملکرد مدل‌های آموزش‌داده‌شده را بر روی **داده‌های آزمون** با استفاده از معیارهای زیر ارزیابی کنید:

| معیار | توضیح |
|:---|:---|
| **MSE** (Mean Squared Error) — میانگین مربعات خطا | معیاری برای سنجش میانگین مربع تفاوت بین مقادیر پیش‌بینی‌شده و واقعی |
| **R-squared** ($R^2$) | معیاری برای سنجش میزان واریانس توضیح‌داده‌شده توسط مدل |

### ۶. مقایسه نتایج

نتایج حاصل از مدل‌های مختلف را از طریق **رسم نمودار** مقایسه کنید.

## ⚠️ نکته مهم
